# 💳 Fraud Detection System

A Machine Learning based Fraud Detection Web Application built using Python, Scikit-learn, and Streamlit.

---

## 🚀 Features

- Fraud transaction prediction
- Fraud probability score
- Interactive dashboard
- Pie chart visualization
- Real-time transaction testing
- Streamlit web interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- NumPy
- Matplotlib
- Joblib

---

## 📂 Project Structure

```bash
fraud-detection/
│
├── app.py
├── fraud_model.pkl
├── requirements.txt
├── README.md
└── creditcard.csv
```

---

## ▶️ Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
python -m streamlit run app.py
```

---

## 📊 Dataset

Dataset used:
Credit Card Fraud Detection Dataset

- Contains transaction details
- Detects fraudulent transactions using ML
- Includes PCA-transformed features V1–V28

---

## 🤖 Machine Learning Model

Model Used:
- Logistic Regression

The model predicts whether a transaction is:
- Normal Transaction
- Fraudulent Transaction
